# 액션별 결정 연쇄 표 (Decision Flows)

> 결정 스택 엔진의 사양 문서. "어떤 액션/효과가 어떤 결정을 스택에 push하는가"를 정의한다.
> 아키텍처 원칙(CLAUDE.md): 각 결정 제출 = 원자 트랜잭션, 스택은 DB 저장, 리치 포함 모든 결정은 블로킹.

## 읽는 법

- **자동**: 서버가 결정 없이 즉시 적용하는 효과 (커밋 + 브로드캐스트)
- **push: X (대상)**: 스택에 결정 X를 올림. 대상이 응답해야 다음으로 진행
- 표의 순서 = 스택 해소 순서. 중첩 결정(결정이 결정을 낳음)은 들여쓰기로 표기
- FE는 제출 전 단계별 UI(칸 하이라이트, 비용 계산)를 로컬로 진행하고, **완성된 결정 하나**를 제출한다

## 1. 결정 타입 카탈로그

| 결정 타입 | 대상 | 페이로드 | 발생 원인 |
|---|---|---|---|
| LEECH_RESPONSE | 이웃 (시계방향 순) | 수락/거절 (+타클론: 토큰/충전 순서) | 건물 배치·업그레이드·검은행성 등 파워값 있는 건물 생성 |
| CHOOSE_TECH_TILE | 본인 | 기본/확장/고급 타일 선택 (고급이면 +덮을 타일, +조건 충족 확인) | 연구소·아카데미 건설, REBELLION_TECH, TWILIGHT_UPGRADE, GAIN_BASIC_TECH_TILE 연방 타일, 아이타 가이아 페이즈, 연방 결성 시 |
| CHOOSE_TECH_TRACK | 본인 | 전진할 트랙 | COMMON/EXPANSION 기본 타일, 모든 고급 타일, ECLIPSE_TECH |
| PLACE_MINE | 본인 | 대상 헥스 (+테라포밍 지불 방식) | 무료 광산 효과 (BASIC_EXP_TILE_3, FED_EXP_TILE_5/7, 부스터 13·14 후속, 파워 액션 테라포밍 후속, ECLIPSE_MINE, 스페이스 자이언트 액션) |
| PLACE_BLACK_PLANET | 본인 | 대상 EMPTY 헥스 | 항법 트랙 5단계 진입 |
| PLACE_GAIAFORMER | 본인 | 대상 차원 변형 헥스 | 가이아 프로젝트 액션, BOOSTER_12, TF_MARS_GAIAFORM |
| CHOOSE_FEDERATION_TILE | 본인 | 공급처의 타일 선택 | 연방 결성, 하이브 7의 배수 도달 |
| CHOOSE_FED_TOKEN_REUSE | 본인 | 재발동할 보유 연방 토큰 | TWILIGHT_FED, ARTIFACT_13 |
| CHOOSE_ARTIFACT | 본인 | 공급처(4개 중 미획득) 인공물 | TWILIGHT_ARTIFACT (파워 6 소각) |
| CHOOSE_BOOSTER | 본인 | 남은 부스터 선택 | 패스 (6라운드 제외) |
| CHOOSE_UPGRADE_TARGET | 본인 | 대상 건물 | REBELLION_UPGRADE, TWILIGHT_UPGRADE, 파이락 다운그레이드, 엠바스 스왑 |
| PLACE_SPACE_STATION | 본인 | 대상 EMPTY 헥스 | 하이브 PI 액션 |
| TERRANS_GAIA_CONVERT | 테란 | 가이아 토큰 → 자원 배분 | 가이아 페이즈 (라운드 시작) |
| ITARS_GAIA_TECH | 아이타 | 파워 4개 소모 여부 + 타일 선택 | 라운드 종료 (4개 단위 반복) |
| TINKEROIDS_ACTION_PICK | 팅커로이드 | 이번 라운드 액션 타일 | 라운드 시작 |
| INCOME_POWER_ORDER | 해당 플레이어 | 파워 수입 항목(차징/토큰)의 적용 순서 | 수입 페이즈 — 순서가 결과에 영향을 줄 때만 발생, 플레이어별 병렬 처리 |
| BID_FACTION | 전원 (순번) | 비딩값(VP, 최종 점수에서 차감) 제시 또는 패스 | 게임 셋업 (아래 §4) |
| PLACE_INITIAL_MINE | 전원 (스네이크) | 초기 광산/의회 위치 | 게임 셋업 |

## 2. 메인 액션 8종의 결정 연쇄

### A1. 광산 건설

```
제출: {대상 헥스, 테라포밍/QIC 지불 명세}
1. 서버 검증: 항해 거리, 행성 타입·테라포밍 비용, 자원, 재고    [자동]
2. 자원 차감 + 광산 배치 커밋                                  [자동]
3. 파생 이벤트: 라운드 점수(광산/테라포밍/새 섹터/새 행성 종류/가이아),
   패시브 VP(BASIC_TILE_8, ADV_TILE_16, 글린 가이아 +2VP),
   기오덴/다카니안/란티다 PI 지식·자원, 연방 자동 편입           [자동]
4. push: LEECH_RESPONSE (파워값 있는 이웃, 시계방향 순)
5. 턴 종료
```

- 가이아 행성: 테라포밍 대신 QIC (글린은 광석). 차원 변형에는 광산 불가(가이아 변환 후 가능)
- 란티다 기생 광산: 상대 행성 위 배치, 3단계 파생 이벤트 상이

### A2. 가이아 프로젝트 시작 (가이아포머 배치)

```
제출: {대상 차원 변형 헥스, QIC 사용}
1. 검증: 가이아 트랙 ≥1, 포머 재고, 항해 거리                  [자동]
2. 파워 6/4/3(트랙 레벨별) → 가이아 구역 이동, 포머 배치        [자동]
3. 턴 종료 (리치 없음 — 포머 파워값 0)
```

- 다음 가이아 페이즈: 헥스 GAIA 변환 + 가이아 구역 파워 복귀(테란 bowl2 → push: TERRANS_GAIA_CONVERT)

### A3. 건물 업그레이드 — **가장 깊은 연쇄 (v1 버그 다발 지점)**

```
제출: {대상 건물, 목표 건물}
1. 검증: 업그레이드 경로, 비용(교역소는 2거리 내 타인 건물 여부), 재고   [자동]
2. 자원 차감 + 건물 교체 커밋 (이전 건물 재고 반환)                     [자동]
3. 파생: 라운드 점수(교역소/연구소/PI/아카데미), ADV_TILE_17,
   종족 PI 건설 트리거(글린 토큰 자동 지급, 제노스 연방 7→6,
   발타크 항해 잠금 해제, 매드 안드로이드 티타늄 +1 등)                        [자동]
4. push: LEECH_RESPONSE (이웃들)
5. [연구소·아카데미 건설 시] push: CHOOSE_TECH_TILE (본인)
   5a. 기본 타일 (트랙 소속) → 트랙 1칸 무료 전진 + 레벨 보상    [자동]
   5b. 기본 타일 (COMMON/EXPANSION) → push: CHOOSE_TECH_TRACK
   5c. 고급 타일 → 조건 검증(트랙 레벨 4+ 또는 COMMON 조건,
       연방 토큰 플립, 선점) + push: 덮을 타일 지정(페이로드)
       → 즉발 효과 [자동] → push: CHOOSE_TECH_TRACK
   5d. BASIC_EXP_TILE_3 획득 시 → push: PLACE_MINE (2삽 무료)
       → 광산 커밋 → push: LEECH_RESPONSE → (파생 이벤트 재귀)
6. [트랙 전진이 4→5 도달 시]
   6a. 검증: 5단계 미점유 + 연방 토큰 플립                       [자동]
   6b. 테라포밍 5 → 트랙 꼭대기 연방 타일 획득                   [자동]
   6c. 항법 5 → push: PLACE_BLACK_PLANET
       → 검은행성 커밋 → push: LEECH_RESPONSE → 파생 이벤트
   6d. 가이아 5 → 가이아 행성당 1VP + 4VP                        [자동]
   6e. 경제 5 → 6c+3o+파워 6 순환 / 지식 5 → 지식 9              [자동]
7. 턴 종료
```

### A4. 연방 결성

```
제출: {포함 건물 목록, 위성(토큰) 헥스 목록}
1. 검증: 파워 합 ≥7 (제노스 PI 6, 하이브 (n+1)×7),
   연결성 + Steiner 최소 토큰 수, 위성 배치 규칙                 [자동]
2. 위성 비용 차감(파워 토큰 / 하이브 QIC), 연방 그룹 커밋        [자동]
3. push: CHOOSE_FEDERATION_TILE (본인)
4. 타일 즉시 보상 + 라운드 점수(연방 결성)                       [자동]
   4a. [FED_EXP_TILE_1 선택 시] push: CHOOSE_TECH_TILE → (A3의 5a~5d 재귀)
   4b. [FED_EXP_TILE_5/7 선택 시] push: PLACE_MINE → 리치 → 재귀
5. 턴 종료
```

### A5. 연구 전진 (지식 4)

```
제출: {트랙}
1. 검증: 지식 4, 트랙 최대치, 발타크 항법 잠금, 4→5 조건        [자동]
2. 차감 + 전진 + 레벨 보상 + 라운드 점수(연구) + ADV_TILE_18    [자동]
3. [4→5] A3의 6a~6e와 동일 (항법 5면 push: PLACE_BLACK_PLANET → 리치)
4. 턴 종료
```

### A6. 파워 액션 / 함대 액션 (공용 보드, 라운드당 전체 1회)

| 액션 | 연쇄 |

| PWR_KNOWLEDGE/ORE/CREDIT/KNOWLEDGE_2/PWR_TOKEN | 즉시 적용 → 턴 종료 [자동] |
| PWR_TERRAFORM / PWR_TERRAFORM_2 | push: PLACE_MINE (삽 크레딧 적용) → 광산 커밋 → push: LEECH_RESPONSE → 파생 |
| TF_MARS_VP / ECLIPSE_VP / REBELLION_CONVERT | 즉시 적용 (+ADV_TILE_21 4VP) [자동] |
| TF_MARS_GAIAFORM | push: PLACE_GAIAFORMER → 즉시 GAIA 변환 [자동] |
| TF_MARS_TERRAFORM / TWILIGHT_NAV | **즉시 사용** ✅확정 — 액션 실행 즉시 push: PLACE_MINE (버프 적용, 같은 턴) → 커밋 → push: LEECH_RESPONSE. 이월되는 버프 없음 |

| REBELLION_UPGRADE / TWILIGHT_UPGRADE | push: CHOOSE_UPGRADE_TARGET → 업그레이드 커밋 → push: LEECH_RESPONSE → [TWILIGHT_UPGRADE] push: CHOOSE_TECH_TILE 재귀 |
| TWILIGHT_FED | push: CHOOSE_FED_TOKEN_REUSE → 보상 적용 → [특수 액션 토큰이면] 해당 후속 push |
| TWILIGHT_ARTIFACT (파워 6 소각) | push: CHOOSE_ARTIFACT → 즉발/수입 적용 → [ARTIFACT_13] push: CHOOSE_FED_TOKEN_REUSE |

### A8. 패스

```
제출: {부스터 선택 (1~5라운드) 또는 패스만 (6라운드)}
1. 패스 VP 정산: 부스터 패스 점수 + ADV_TILE_11~15              [자동]
2. [1~5R] 부스터 교체 (CHOOSE_BOOSTER는 제출 페이로드에 포함)
3. 발타크: 잔여 포머 → QIC 자동 변환                            [자동]
4. 패스 순서 기록 (다음 라운드 턴 순서)                          [자동]
```

### A9. 함대 입장 (Lost Fleet 추가 액션)

```
제출: {대상 함대}
1. 검증: 함대당 1회, 인당 최대 3, VP 5 (발타크 7)               [자동]
2. 종족 비용: 네블라/아이타 토큰 1 영구 소각,
   타클론 push: 브레인스톤 가이아 이동 확인(페이로드로 흡수 가능) [자동]
3. 입장 순서 보너스 (2·3번째 파순 2, 4번째 파순 3)              [자동]
4. 해당 함대 액션 1·2번 활성화                                  [자동]
```

## 3. 라운드 경계의 결정

| 시점 | 결정 | 대상 |
|---|---|---|
| 라운드 시작 (수입) | INCOME_POWER_ORDER — 파워 차징/토큰 수입의 적용 순서 선택 ✅확정 (v1도 플레이어 선택으로 구현되어 있었음). 순서가 결과를 바꾸는 경우에만 결정 발생, 아니면 자동 적용. 플레이어별 독립이므로 병렬 처리 | 전원 (해당자만) |
| 가이아 페이즈 | TERRANS_GAIA_CONVERT (가이아 토큰 배분) | 테란 |
| 라운드 시작 | TINKEROIDS_ACTION_PICK | 팅커로이드 |
| 라운드 종료 | ITARS_GAIA_TECH (파워 4개 → 타일, 반복) → CHOOSE_TECH_TILE 재귀 | 아이타 |

## 4. 셋업 페이즈의 결정 (순차 진행)

1. 방 생성 → 4명 입장
2. 맵 자동 생성 — **수동 회전(MAP_ROTATE) 단계 제거** ✅확정: 자동 배치의 행성 충돌 해소(같은 행성 타입 거리 ≤1 회피)가 보장되면 맵을 돌릴 필요가 없음. 충돌 해소를 셋업 알고리즘의 필수 요건으로 승격
3. BID_FACTION: **종족 비딩** ✅절차 확정
   - **후보 종족 = 인원수만큼(4종) 랜덤 드로우** — 전 종족이 아니라 이 후보를 놓고 경매 ✅확정 (2026-07-08)
   - **같은 홈행성(색)의 두 종족은 후보에 동시 등장 불가** (18종 = 9행성 × 2종족) ✅확정 (2026-07-22)
   - 1번 플레이어부터 비딩값(VP) 입력하며 진행
   - 플레이어들이 돌아가며 값을 올리거나 패스 → **나머지 전원이 패스하면** 그 플레이어가 후보 중 종족 선택
   - 남은 플레이어들로 같은 방식 반복 — 마지막 1인은 남은 후보를 비딩 0으로 받는다
   - 비딩값은 최종 점수에서 차감
   - **턴 순서 결정** ✅확정 (2026-07-21):
     - **모드 a (종족+턴 고정)**: 후보 4종이 드로우 시점에 턴 슬롯에 사전 고정된다 (`board.bidSlotFactions`, index+1 = 턴 — 예: [발타크, 하이브, 제노스, 팅커로이드] = 1~4턴). 낙찰자가 종족을 고르면 **그 종족의 슬롯 턴**을 함께 가져간다. 낙찰 순서 ≠ 턴 순서
     - **모드 b (턴 선택)**: 낙찰자가 남은 턴 슬롯(1~4) 중 원하는 순번을 직접 선택 (`turnSlot` 페이로드)
     - 두 모드 모두 `board.bidTurnSlots`("1"~"4" → playerId)가 채워지고, 전원 배정 시 슬롯 순으로 turnOrder 확정
4. PLACE_INITIAL_MINE: **기본종족 스네이크(1→4→4→1) → 제노스 3번째 광산 → 확장종족(좌석순 1회: 광산, 팅커로이드는 의회) → 하이브(placeLast) 의회** ✅확정 (2026-07-21) — 확장 종족은 좌석이 빨라도 기본종족 스네이크에 끼지 않는다
5. CHOOSE_BOOSTER: 역순(4→1) 부스터 선택
6. 1라운드 시작

## 5. 엔진 구현 규칙 요약

- 모든 push는 **커밋과 같은 트랜잭션**에서 이뤄진다 (커밋됐는데 결정이 안 쌓이는 상태 없음)
- 재귀 깊이 제한 없음 — 스택이 비면 턴 종료 판정
- LEECH_RESPONSE는 전원 동시 오픈 — 블록 내 순서 무관 응답, 전원 응답 후 다음 결정 진행 (✅확정 2026-07-23)
- 자동 응답: 1파워 무비용 리치 자동 수락 (아이타·타클론 PI는 예외), 개인 설정 범위, 방 타이머
- 모든 결정 제출은 `(게임 상태 버전, 결정 ID)`를 포함 — 불일치 시 거부 + 리싱크
- 언두: 턴 시작 마커 이후 로그 무효화 (상대 응답 존재 시 동의 필요 — CLAUDE.md 참조)
