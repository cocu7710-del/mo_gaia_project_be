# 엣지 케이스 룰 정의

> v1에서 버그가 났거나 룰이 모호했던 지점들의 확정 룰. 전 항목 ✅확정 (2026-07-07 검수 완료).

## 1. 타클론 브레인 스톤

파워 볼 시스템의 모든 규칙에 관여하는 특수 토큰. v1 최다 버그 영역이므로 상호작용별로 전부 정의한다.

| 상황 | 룰 | 상태 |
|---|---|---|
| 기본 성질 | 파워 토큰 1개로 카운트. 볼 Ⅰ→Ⅱ→Ⅲ을 일반 토큰처럼 이동 (1차징 = 1칸) | ✅ |
| 파워 사용 (볼 Ⅲ에서) | 브레인스톤 = **3파워 가치**. 3 미만 비용에 쓰면 잔여분 소멸 (거스름 없음) | ✅ |
| 사용 시 선택권 | 비용 지불에 브레인스톤을 쓸지 일반 토큰을 쓸지는 **플레이어가 선택** (자동 최적화하지 않음 — 결정 페이로드에 포함) | ✅ |
| 충전 순서 | 충전 시 브레인스톤 우선 이동 (v1 방식 유지 — 볼Ⅲ의 3파워 가치가 거의 항상 유리) | ✅ |
| 파워 소각 | 소각(볼Ⅱ 2개 제거 → Ⅲ에 1개)에서 브레인스톤은 소각 "제거분"으로 선택 가능 — 단 경고창 필수 (아래 영구 제거와 동일 정책) | ✅ |
| 영구 제거 | 위성 비용, 함대 입장 소각, 인공물 획득(파워 6 제거) 등에서 **제거 가능** — 단, 브레인스톤이 제거 대상이 되려 할 때 **FE 경고창(확인 다이얼로그) 필수** | ✅ |
| 함대 입장 | 브레인스톤을 가이아 구역으로 이동해야 입장 가능 (이동 불가 상태면 입장 불가) | ✅ (v1, LF 자체 룰) |
| 가이아 구역 복귀 | 가이아 페이즈에 일반 토큰과 함께 볼Ⅰ로 복귀 | ✅ |
| PI 리치 | 리치 수락 시 파워 토큰 +1. **토큰 먼저/충전 먼저 순서를 리치 응답 페이로드에서 선택** (먼저 받은 토큰이 이번 충전 대상이 되는지 갈림) | ✅ |
| 1파워 리치 | 타클론 PI 보유 시 1파워 무비용 리치도 자동 수락하지 않음 (수동 응답 — 토큰/순서 선택 때문) | ✅ |
| 수입 페이즈 | INCOME_POWER_ORDER 결정에서 브레인스톤도 충전 대상에 포함 | ✅ |
| 최종 점수 (잔여 자원) | 볼Ⅲ의 브레인스톤 = 자원 **1**로 계산 (v1의 2 계산은 폐기) | ✅ |

## 2. 하이브(Ivits) 연방 선언

v1 버그 영역. 확정 룰:

- **연방 그룹은 항상 1개** — 새 "결성"은 기존 그룹의 확장이다. 기존 그룹의 건물·위성과 연결되고 파워를 합산한다 (건물 중복 카운트 금지)
- n번째 연방 타일 획득 목표 파워 = **(획득한 타일 수 + 1) × 7**
- 위성 비용: 파워 토큰이 아니라 **QIC 1개/위성**
- 위성 배치: EMPTY 헥스만, 함대 헥스 불가. 일반 종족의 "자기 기존 연방 인접 6방향 배치 불가" 제한은 **하이브에게 적용하지 않음** (단일 그룹 확장이므로)
- 우주정거장: 건물 취급(파워 1), 연방 구성 요소로 사용 가능, 배치 시 리치 없음 ✅, 인접 연방 자동 편입
- **파워 합산은 모든 경로에서 보정 포함 값을 사용** — BASIC_TILE_9(+1), 모웨이드 링(+2), 매드 안드로이드 티타늄(+1), 란티다 기생 광산(=1)을 검증·표시·확정 어디서든 동일 함수로 계산 (v1은 검증 경로마다 다른 함수를 써서 불일치 — 단일 `buildingPowerValue()` 강제)
- 7의 배수 도달 시 타일 획득은 **자동 발동이 아니라 연방 결성 액션으로 선언** (v1 동작 유지)

## 3. 고급 기술 타일 획득

v1 버그 영역 (우회 경로 무검증). 확정 룰 — 서버가 아래 순서로 전부 검증:

1. 대상 타일이 오퍼에 존재하고 **미선점** (타일당 1명, 선착순)
2. 본인이 같은 타일 미보유
3. **조건**: 트랙 소속 타일 → 해당 트랙 **레벨 4 이상** / COMMON 타일 → 게임별 조건 (VP 25+ 또는 함대 3+)
4. **사용 가능한 연방 토큰 1개 플립** (없으면 획득 불가)
5. **덮을 기본 타일 지정 필수** — 본인 소유·미덮임 타일만. 덮인 타일의 수입/패시브/액션은 즉시 비활성
6. 획득 후 **선택한 트랙 1칸 전진** (기본 타일 획득과 동일한 전진 규칙 적용)
7. 그 전진이 4→5라면: 5단계 미점유 확인 + **연방 토큰 1개 추가 플립** (4번과 별개 — 최대 2개 소모). 토큰이 없으면 전진만 스킵하고 타일은 획득
8. 즉발 효과 적용

- 덮기 대상: 기본 9종 + 확장 3종(BASIC_EXP) 모두 가능 ✅
- FE의 commit 방식 우회 경로는 존재하지 않음 (서버 권위 — 모든 획득은 이 검증을 통과)

## 4. 파워 리치 상세

- 트리거: 파워값 있는 건물의 배치/업그레이드 (광산, 교역소, 연구소, PI, 아카데미, 검은행성 광산). 가이아포머(0)·우주정거장 배치는 리치 없음 ✅
- 대상: 트리거 건물에서 **헥스 거리 2 이내**에 건물이 있는 상대. 기준량 = 그 상대의 거리 2 이내 건물 중 **최대 파워값** (보정 포함)
- 실충전 가능량 = min(기준량, bowl1×2 + bowl2 (+브레인스톤 보정)). 0이면 오퍼 생략
- VP 비용 = 실충전량 − 1. **VP 부족 시**: min(보유 VP + 1, 실충전량)으로 축소 오퍼
- 1파워(무비용) 오퍼는 자동 수락 — 예외: 아이타, 타클론 PI 보유자는 수동 ✅
- 응답 순서: 트리거 플레이어 기준 시계방향, 블로킹 (CLAUDE.md 확정 사항)
- **패스한 플레이어도 리치 가능** (1~5라운드) ✅. **6라운드 패스자는 예외**: 1파워(무비용) 오퍼만 자동 수락으로 지급 (모든 종족 — 아이타·타클론 PI의 수동 예외도 이 경우엔 자동), 2파워 이상 오퍼는 발생하지 않음 ✅
- 한 액션에서 여러 건물이 생기면 (예: 업그레이드 + 무료 광산) 각 건물마다 별도 리치 배치 발생, 발생 순서대로 해소

## 5. 아카데미

- **지식형 / QIC형 2종 체계 유지** (v1 단순화 채택 — 공식의 좌/우와 기능적으로 동일) ✅
- 지식형: 수입 지식 2 (아이타는 3)
- QIC형: 라운드당 1회 QIC +1 특수 액션 (발타크는 QIC 대신 크레딧 4)
- 같은 종류 아카데미 2개 건설 **불가 — 지식형 1 + QIC형 1 고정** ✅

## 6. 최종 점수 타일 정의 확정

- FINAL_TILE_FEDERATION_POWER → **FINAL_TILE_SATELLITES로 개명**: "가장 많은 위성" — 연방 그룹의 위성(토큰 헥스) 개수 합. 하이브의 QIC 위성도 동일 카운트 ✅
- FINAL_TILE_SECTORS_WITH_BUILDINGS: 딥 섹터 **제외 유지** — 딥 섹터는 별도 타일(FINAL_TILE_DEEP_SECTORS)이 있으므로 중복 배제 ✅
- 동점 처리: 해당 등수들의 VP 합 ÷ 인원 (정수 내림), 달성도 0이면 순위 VP 없음 ✅ (v1 유지)

## 7. 라운드/페이즈 경계

- **가이아 페이즈 순서** (라운드 시작): ① 가이아포머 있는 차원 변형 헥스 → 가이아 변환 ② 가이아 구역 파워 복귀 (테란은 bowl2 + TERRANS_GAIA_CONVERT 결정) ③ 수입 적용 (INCOME_POWER_ORDER)
- **아이타 가이아 테크** (라운드 진입 종족 능력 페이즈 — 수입·가이아 후, 턴 순서대로, 2026-07-22 rule-audit B-1로 정정): 가이아 구역 파워 4개 단위로 "제거하고 기술 타일 획득(기본/고급 무관)" 선택 반복. 6라운드 종료 후에는 발동 없음. 획득한 타일의 트랙 전진·연쇄는 decision-flows A3의 5a~5d와 동일하게 즉시 해소
- **발타크**: 패스 시 잔여 가이아포머 자동 QIC 변환. 라운드 시작 시 변환된 포머 반환
- **매드 안드로이드 최저 트랙 +1**: 최저 레벨 트랙이 여러 개면 그중 선택 (CHOOSE_TECH_TRACK, 해당 트랙들로 제한). 4→5 전진도 가능하되 일반 5단계 진입 조건(미점유+연방 토큰) 적용
- **팅커로이드**: 라운드 시작 액션 선택은 수입 적용 전. 미선택 시 타이머로 기본값(첫 번째) 적용 ✅

## 8. 기타 확정

- **부스터 풀**: 기본/확장 구분 없이 **14종 단일 풀에서 인원+3개(=7개) 랜덤** (v1 유지 — 확장판 상시 적용 게임이므로) ✅
- **FED_TILE_3 (12VP)**: 획득 즉시 사용 처리(뒤집힌 상태로 지급) — 고급 타일/5단계 진입용 플립에 사용 불가. 단 연방 토큰 **개수**로는 카운트 (ADV_TILE_5/13, 최종 점수) ✅ (v1 유지)
- **연방 자동 편입**: 새 건물이 자기 연방 그룹에 인접하면 자동 편입 (파워 재계산, 추가 보상 없음) ✅ (v1 유지)
- **글린 QIC→광석 변환**: QIC형 아카데미 건설 "전까지" 모든 QIC 획득에 적용 (트랙 보상·타일·리베리온 변환 포함). 항해 4→5 진입은 연방 토큰만 쓰므로 영향 없음. 가이아 입장은 광석으로 지불 ✅
- **란티다 기생 광산**: 상대 행성에 건설. 파워값 1 고정, 행성 종류·섹터·가이아 카운트에서 제외, 연방 구성 파워 1, PI 보유 시 +지식 2. 원 소유자에게 리치 발생 ✅ (v1 유지)

## 확정 이력 (2026-07-07 검수)

1. 브레인스톤 볼Ⅲ 잔여 자원 = **1** (v1의 2 폐기)
2. 브레인스톤 영구 제거 **가능** — 단 제거 대상이 될 때 FE **경고창 필수**
3. 패스 후 리치 허용. **6라운드 패스자는 1파워 자동 수락만** (모든 종족), 그 외 오퍼 미발생
4. 아카데미 지식형 1 + QIC형 1 고정
5. FINAL_TILE_SATELLITES 개명, 위성 개수 기준 (하이브 QIC 위성 포함)
6. "건물 있는 섹터 수"는 딥 섹터 제외 유지
7. 부스터 14종 단일 풀 유지
8. 고급 타일 덮기 대상에 BASIC_EXP 포함
