### 종족별 능력

**1. 제노스**: 셋업 광산 3개. 프리 액션: 광석 1 → bowl3 파워 1. PI 수입(총량) 파워 순환 4 + QIC 1 — 토큰 없음. PI 패시브: 연방 필요 파워 7→6.

**2. 글린**: QIC 아카데미 건설 전까지 획득 QIC → 광석 자동 변환. 가이아 행성 건설 시 +2VP, 가이아 입장 시 QIC 대신 광석 1. PI 건설 시 전용 연방 토큰(2c+1o+1k) 즉시 지급. PI 수입(총량) 파워 순환 4 + 광석 1 — 토큰 없음. **2거리 점프(라운드 1회, 액션, 즉시 사용)** — 확장 공식 룰. PI 토큰은 건설 시 자동 지급만 (✅v1의 반복 구매 액션 제거 확정).

**3. 타클론**: 브레인스톤 = 파워 1토큰으로 카운트, 사용 시 3파워 가치(잔여 미반환), 충전 시 우선 이동. PI 패시브: 리치 수령 시 파워 토큰 +1 (토큰/충전 순서 선택). 1파워 리치도 거절권. 함대 입장 시 브레인스톤 가이아 구역 이동 필요 — 이동 불가(영구 제거·이미 가이아)면 입장 불가.

**4. 엠바스**: 기본 수입 광석 2 + 지식 1. PI 수입 +토큰 2. PI 액션(라운드 1회): 광산 ↔ PI 위치 교환 (리치 없음, 검은행성 광산 제외).

**5. 하드쉬 할라**: 기본 수입 크레딧 3 + 광석 1 + 지식 1. PI 프리 액션: 3c→광석 1, 4c→지식 1, 4c→QIC 1.

**6. 하이브 (Ivits)**: 셋업에서 광산 대신 PI (항상 마지막 배치). 연방 1개만 소유하며 누적 확장 — n번째 결성 목표 파워 = (결성횟수+1)×7, 위성 비용 QIC. PI 액션(라운드 1회): 빈 헥스에 우주정거장(파워 1) 배치, 항해 거리 적용. PI 수입 +QIC 1.

**7. 기오덴**: PI 패시브: 새 행성 타입 개척 시 +지식 3.

**8. 발타크**: PI 건설 전까지 항해 트랙 전진 불가. 프리 액션: 가이아포머 1 → QIC 1 (다음 라운드 반환). QIC 아카데미: QIC 대신 크레딧 +4. 함대 입장 비용 VP 7 (일반 5).

**9. 란티다**: 기생 광산 — 상대 건물 있는 행성에 광산 건설 가능 (파워값 1 고정, 연방 파워 1). 섹터·건물 수 카운트에 포함, 행성 종류 카운트에서만 제외. PI 패시브: 기생 광산 건설 시 +지식 2. PI 수입 파워 순환 4만 (토큰 없음). 기본 수입 +파워 토큰 1 — 확장 공식 룰.

**10. 테란**: 가이아 구역 파워가 라운드 시작 시 bowl2로 복귀 (일반은 bowl1). PI 패시브: 가이아 토큰 → 자원 수동 배분 (1토큰=1c, 3=1o, 4=1q, 4=1k).

**11. 파이락**: 기본 수입 광석 1 + 지식 2. PI 액션(라운드 1회): **연구소 → 교역소 업그레이드 액션(비용 무료) + 지식 트랙 1칸 무료 전진** ✅명명 확정 — 일반 업그레이드와 동일 취급이므로 리치·교역소 건설 라운드 점수가 자연 발생 ("다운그레이드" 표현 사용 금지).

**12. 매드 안드로이드**: 기본 수입 광석 1만. 건물 수입 스왑: 교역소 = 1개당 지식 1, 연구소 = 3/4/5 크레딧. 업그레이드 경로 스왑: 교역소 → 연구소/아카데미, 연구소 → 의회. 특수 액션(라운드 1회): 최저 레벨 트랙 하나 +1 (지식 무료). PI 패시브: 티타늄 행성 위 건물 파워값 +1 (리치·연방 공통).

**13. 네블라**: 프리 액션: bowl3 토큰 1 → 가이아 구역 + 지식 1. 연구소 수입 스왑: 지식 대신 1개당 파워 순환 2. PI 패시브: bowl3 토큰 1개 = 2파워 (잔여 미반환), 전용 변환(2토큰→1o+1c, 3토큰→2o), 최종 점수 잔여 자원 계산 시 bowl3 2배. 함대 입장 시 토큰 1개 영구 소각.

**14. 아이타**: 기본 수입 +파워 토큰 1. 파워 소각 시 소각분 1개가 가이아 구역으로. 지식 아카데미 수입 3 지식 (일반 2). 1파워 리치 거절권. PI 능력: 라운드 진입 종족 능력 페이즈(가이아 페이즈 후, 턴 순서대로)에 가이아 구역 파워 4개 제거 → 기술 타일 1개, 기본/고급 무관 (반복 가능, 6라운드 종료 후엔 없음). 함대 입장 시 토큰 1개 영구 소각.
