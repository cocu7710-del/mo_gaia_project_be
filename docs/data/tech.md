## 4. 타일 슬롯 배치·획득 규칙

### 배치 (셋업)

- 기본 9장 셔플 → 트랙 6개 아래 각 1장 + **자유(COMMON) 슬롯 3장**
- 확장 3장 셔플 → EXPANSION 슬롯 3개 (position 10~12)
- 고급 21종 중 7개 랜덤 → 트랙 6개 + **COMMON 슬롯 1개** (7번째)
- COMMON 고급 타일 획득 조건은 게임별 랜덤: **VP 25 이상** 또는 **입장 함대 3개 이상**

### 기본 타일 획득

- 트리거: 연구소/아카데미 건설(업그레이드), REBELLION_TECH 함대 액션, GAIN_BASIC_TECH_TILE 연방 타일, 연방 형성 시 지정, 아이타 가이아 페이즈
- 트랙 소속 타일 → 해당 트랙 1칸 무료 전진 + 레벨 보상. COMMON/EXPANSION → 선택한 트랙 전진
- 전진 스킵 조건(타일만 획득): 발타크 항해 잠금 / 5단계 점유 / 4→5인데 연방 토큰 없음 / 이미 5단계
- 같은 타일을 여러 플레이어가 가질 수 있음 (본인 중복만 금지)

### 고급 타일 획득 (v1 버그 영역)

v1 정상 경로의 검증 순서 (새 설계에서도 이 순서 유지 권장):
1. 오퍼 존재 + **선점 확인** (타일당 1명)
2. 본인 중복 소유 불가
3. 조건: 트랙 타일 → **해당 트랙 레벨 4 이상** / COMMON → 게임별 조건(VP 25 또는 함대 3)
4. **연방 토큰 1개 플립 필수**
5. **덮을 기본 타일 필수 지정** (미보유/이미 덮임 불가)
6. 선점 마킹 → 플레이어 기록
7. 선택 트랙 1칸 전진 (4→5면 연방 토큰 재확인, 5단계 점유 시 스킵)
8. 즉발 효과 적용

⚠️ **v1 버그 원인 추정**: commit-turn("C안") 우회 경로가 FE가 보낸 타일 획득을 **아무 조건 검증 없이 저장** (레벨 4, 연방 토큰, 커버 체크 전부 없음). 검증이 FE에만 있어 고급 타일 획득 버그의 진원지로 추정. → **새 설계: 서버 권위 원칙으로 우회 경로 자체를 없앰**
